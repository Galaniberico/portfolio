Technical decisions and scope +

Credentials on the device. Local protection with keys managed by Android Keystore and, on iOS, AES encryption with a key stored in Keychain.

Hardware interaction. UUID-filtered BLE scanning, connection, credential transmission, error handling and timeouts.

Documented scope. NFC/HCE implemented on Android. Integration with the external authentication service and real-time web monitoring were not completed in the documented version.
