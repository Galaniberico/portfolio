Authenticate on the phone

Illustrative flow for an authorised access request; no live hardware connection or real timings. Server synchronisation is shown separately from door opening.

Two native platforms

Kotlin and Jetpack Compose on Android. Swift and SwiftUI on iOS. MVVM architecture and local authentication on both; BLE on both, and NFC/HCE on Android.

My contribution

I implemented the apps, backend, web interface and remaining software, except the reader code and controller–reader communication, which other team members developed.

Technical decisions and scope

Credentials on the device. Local protection with keys managed by Android Keystore and, on iOS, AES encryption with a key stored in Keychain.

Hardware interaction. UUID-filtered BLE scanning, connection, credential transmission, error handling and timeouts.

Documented scope. NFC/HCE implemented on Android. Integration with the external authentication service and real-time web monitoring were not completed in the documented version.
